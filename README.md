## 项目简介

本工具以「本地优先」为设计原则，面向个人学习与知识沉淀场景。你可以把

`txt`、`markdown`、`html`、`pdf` 等资料上传进来统一管理，通过目录树分类、标签速查、全文搜索快速定位内容，并在每篇文档旁记录自己的备注。

它同时提供**网页版**与**桌面版**两种形态，共用同一套数据，可以随时切换：

| 形态 | 载体 | 特点 |
| --- | --- | --- |
| 网页版 | 浏览器访问 `127.0.0.1:8848` | 界面完整，支持所有操作 |
| 桌面版（WebView2） | pywebview 桌面窗口 | 复用网页版全部功能，界面一致 |
| 桌面版（tkinter 精简） | Python tkinter 窗口 | 轻量阅读器，无登录保护，适合离线阅览 |

## 功能特性

- **授权登录**：首次运行引导设置密码；输错 3 次自动锁定 5 分钟，防暴力尝试
- **密保保护**：修改密码需「原密码 + 密保答案」双重验证
- **多格式资料**：支持 `.txt` / `.md` / `.markdown` / `.html` / `.htm` / `.pdf`
- **目录管理**：无限层级子目录，删除目录不丢资料（自动归入「未分类」）
- **全文搜索**：标题、标签、正文内容全文索引（FTS5），输入即搜
- **标签系统**：标签云浏览、按标签筛选资料
- **在线编辑**：`txt` / `md` 正文可直接编辑保存（带代码编辑体验）
- **个人备注**：每篇文档附带独立备注栏，可收起/展开
- **HTML 安全**：默认「消毒模式」剥除脚本，可选「原始模式」完整渲染 SPA 页面
- **备份迁移**：一键导出 zip（含数据库与全部文件），可整体迁移
- **移动端适配**：窄屏自动切换抽屉式布局，支持安卓手机访问（局域网 `--lan` / Termux 本机运行）

## 技术栈

| 组件 | 选型 | 说明 |
| --- | --- | --- |
| 后端 | Flask 3 | 单进程、单机、纯本地 |
| 数据库 | SQLite + FTS5 | 全文索引 + LIKE 兜底 |
| Markdown 渲染 | `markdown` + `Pygments` | 代码高亮 |
| HTML 消毒 | `bleach` | 严格白名单，剥除脚本/事件属性 |
| 桌面壳 | `pywebview` / `tkinterweb` | 系统 WebView2 内核渲染网页 |
| 前端 | 原生 HTML/CSS/JS | 零外部网络请求 |

## 快速开始

### 环境要求

- Python 3.8+（推荐 3.10+）
- 依赖见 `requirements.txt`，首次运行自动安装

### Web 版（推荐）

方式一：Windows 双击 `启动笔记站.bat`（自动检测 Python 与依赖）。

方式二：命令行启动

```bash
# Linux / macOS
bash run.sh

# Windows
启动笔记站.bat 或 run.bat

# 或手动启动
pip install -r requirements.txt
python app.py
```

启动后浏览器访问：**http://127.0.0.1:8848**

### 桌面版（WebView2 窗口）

双击 `启动笔记站(桌面版).bat`，或执行：

```bash
python desktop_webview.py
```

> 桌面版复用网页版全部功能与登录体系，默认端口自动在 18488–18990 间选取，避免冲突。
> 桌面版依赖 `pywebview` / `tkinterweb`，可单独安装：`pip install -r requirements-desktop.txt`（Web 版与手机版无需安装）。

### 打包成独立 Windows EXE（免装 Python）

把 Python 解释器、全部依赖、前端资源打成一个 exe，拷到任意 Windows 10/11 电脑双击即用，无需安装任何环境：

```bash
# 在 Windows 机器上，项目根目录执行：
build_exe.bat
```

- 前置：Windows + Python 3.10+（仅打包机需要；**用 exe 的人不需要装**）
- 产物：`dist\LocalNotesStation.exe`（单文件，约 55-70MB；可自行重命名为中文名，不影响使用）
- 界面与桌面版完全一致（WebView2 窗口，功能全量）

**EXE 数据存放（便携模式）**

- `notes.db` 与 `uploads\` 生成在 **exe 同目录**
- 备份/迁移：把 exe 所在的整个文件夹拷走即可
- 首次启动较慢（需解包到临时目录），属正常现象

**常见问题**

- 杀毒软件报警：PyInstaller 打包的 exe 常见误报，添加信任即可（已关闭 UPX 压缩降低误报率）
- 打不开窗口：需 WebView2 运行时，Win10/11 一般已内置；缺失时从微软官网装 WebView2 Runtime
- 启动失败排查：查看 exe 旁边的 `desktop_error.log`


### 局域网模式（手机通过 WiFi 访问）

默认服务只监听 `127.0.0.1`（仅本机可访问）。想让**安卓手机**在同一 WiFi 下打开笔记站，用 `--lan` 启动：

```bash
python app.py --lan
```

启动后控制台会打印可供局域网访问的地址（如 `http://192.168.1.5:8848`），登录页底部也会显示该地址。

> **注意事项**
> - 手机与电脑需连接**同一个 WiFi**（或同一局域网）
> - 局域网为明文 HTTP：请在家庭等**可信网络**使用，避免在公共 WiFi 开启；密码与笔记内容不会上传到任何服务器，仅存本机
> - 若手机无法访问，请检查电脑防火墙是否放行 8848 端口
> - 每次启动服务端口固定 8848，访问地址中的 IP 以控制台实际输出为准

### 安卓手机（Termux）本机运行

完全独立地让笔记站跑在**手机自己**上（数据存手机，完全离线，不需要电脑）：

```bash
# 1. 安装 Termux（F-Droid 或酷安下载）
# 2. 将项目目录拷入手机（如 ~/storage/shared/offline-notes-station）
# 3. 在 Termux 中执行：
cd ~/storage/shared/offline-notes-station
bash termux_setup.sh
# 4. 用手机浏览器打开 http://127.0.0.1:8848
```

> 首次运行会自动安装 Python 与依赖（Termux 需要网络一次；装完之后离线可用）。之后每次启动重复第 3 步即可（依赖已装则直接启动）。

### 离线环境（断网部署）

1. 在有网机器上预下载依赖：

   ```bash
   mkdir -p vendor
   pip download -r requirements.txt -d vendor/
   ```

2. 将整个项目目录（含 `vendor/`）拷贝到断网机器
3. 运行 `bash run.sh` 或 `启动笔记站.bat`，脚本会自动从 `vendor/` 离线安装

## 首次使用与登录

### 首次设置密码与密保

首次启动会进入「设置密码」引导页，需要：

1. 设置访问密码（4–128 字符）
2. 选择或自定义一个密保问题，并填写答案（2–128 字符，请牢记）

密保用于登录后的「修改密码」双重验证，一旦忘记只能手动重置（见下）。

### 登录与失败锁定

- 输入密码进入笔记站
- 连续输错 **3 次**，账号锁定 **5 分钟**（页面显示倒计时，解锁后自动恢复）
- 正常登录后会话默认保持 7 天（记住登录）
- 服务进程重启后登录态失效，需重新登录（属预期行为）

### 修改密码

登录后点击右上角「修改密码」按钮，需同时满足：

- 原密码正确
- 密保答案正确

修改成功后强制退出，需使用新密码重新登录。

### 补录 / 更换密保

- 若首次设置时跳过了密保，登录后会显示引导条提示补录
- 在「修改密码 → 去补录/修改密保」或引导条中，验证当前密码后即可设置或更换密保问题

### 忘记密码 / 手动重置

本应用为纯本地离线工具，无法通过互联网找回密码。登录页「忘记密码？」提供指引：

1. 关闭笔记站（包括桌面版与浏览器页面）
2. 用 SQLite 工具打开数据目录下的 `notes.db`
3. 执行：`DELETE FROM app_settings WHERE key IN ('password_salt','password_hash');`
4. 重新启动，重新进入「首次设置密码」引导

> 提示：仅清空密码，原有笔记数据不受影响。

## 资料管理

### 目录结构

- 顶部「＋目录」新建根目录
- 目录节点上的 `＋` 新建子目录、`✎` 重命名、`🗑` 删除
- 删除目录后其下资料自动归入「未分类」，不会丢失

### 上传资料

点击「⬆ 上传」，选择文件并填写：

| 字段 | 说明 |
| --- | --- |
| 文件 | 仅支持 txt / md / html / pdf |
| 标题 | 留空则使用文件名 |
| 归入目录 | 可选，默认「未分类」 |
| 标签 | 输入后回车添加，可多个 |
| 渲染模式 | 仅 HTML 生效：消毒模式（默认）/ 原始模式 |

> **渲染模式注意**：上传 `.html` 默认以「消毒模式」展示（脚本不执行）；如需完整渲染 SPA / 带脚本页面，请选择「原始模式」并确保文件来自可信来源。

### 新建笔记

点击「＋笔记」，选择 `txt` 或 `md` 格式，填写标题、标签与正文（支持 Markdown 语法），保存后即可在目录树中打开。

### 打开与阅读

- 左侧目录树点击文档即可阅读
- `md` 渲染为富文本；`txt` 等宽排版；`html` 按所选模式渲染；`pdf` 提供下载阅读

### 编辑信息 / 编辑正文

- 「⚙ 信息」：修改标题、标签、HTML 渲染模式
- 「✍ 编辑内容」：`txt` / `md` 文档可直接在线修改正文并保存，全文索引同步更新

### 个人备注

- 每篇文档右侧有「我的备注」栏，可收起/展开（工具栏「💬 备注」）
- 备注与文档分离存储，互不影响

### 删除资料

点击「🗑 删除」，确认后删除文档记录及其在 `uploads/` 中的源文件，不可恢复。

## 数据备份与迁移

- 点击「⤓ 导出」下载 zip 备份，内含 `notes.db` 与 `uploads/` 全部文件
- 迁移：将 zip 拷至新机器，通过 `http://127.0.0.1:8848/api/import` 上传恢复（登录后访问）
- 也可以手动备份：直接复制整个项目目录（`notes.db` + `uploads/`）即可

```
├── uploads/                # 上传文件存储（运行生成）
└── notes.db                # SQLite 数据库（运行生成）
```

## 安全设计

- **零外联**：全程无外部网络请求（无 CDN、无在线字体、无在线 JS）
- **仅监听本机**：默认绑定 `127.0.0.1` 不对外暴露；`--lan` 模式需在可信网络下使用（详见「局域网模式」）
- **HTML 消毒**：默认通过 `bleach` 严格白名单清洗，剥除脚本与事件属性
- **文件名防护**：`secure_filename` + 随机前缀，防目录穿越与重名覆盖
- **密码存储**：PBKDF2-HMAC-SHA256 加盐哈希，明文不落盘
- **失败锁定**：连续 3 次错误锁定 5 分钟，降低暴力破解风险
- **进程级密钥**：会话密钥每次启动随机生成，重启即过期

## 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 忘记登录密码 | 见「忘记密码 / 手动重置」章节，删除密码两条配置后重新设置 |
| 忘了密保答案，无法改密码 | 同上：重置密码后登录，再重新补录密保 |
| 端口 8848 被占用 | 关闭占用进程，或改用桌面版（自动选空闲端口） |
| 桌面版打开是旧画面 | WebView2 有缓存，重启程序或硬刷新一次 |
| 页面出现「未设置密保」提示条 | 点击「去补录」完成密保设置即可（或点「稍后」24 小时内不再提醒） |
| 上传 HTML 页面显示空白 | 该文件为 SPA/脚本页面，请在「⚙ 信息」切换为「原始模式」 |
