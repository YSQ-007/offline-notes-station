# 欢迎使用本地离线笔记站

这是一个**完全本地、离线可用**的个人学习笔记站，用于在断网/专网环境中整理与速查自己的技术笔记。

## 你可以做什么

- **上传资料**：支持 `.txt` / `.md` / `.html` / `.pdf`
- **新建笔记**：直接建 Markdown 或纯文本笔记
- **分类目录**：自定义目录树，把资料归档
- **全文搜索**：按标题、标签、内容快速定位

## Markdown 示例

```bash
python app.py     # 启动 Web 版
python desktop_app.py  # 启动桌面版
```

| 功能 | 说明 |
|------|------|
| 目录树 | 左侧管理资料位置 |
| 标签 | 右侧速查、过滤 |

> 云端同步、联网依赖都没有，数据都存在本地 `notes.db` 与 `uploads/`。
